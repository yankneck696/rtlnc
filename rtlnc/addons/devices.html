Several dongles report the same serial, so software can't tell which physical dongle is which. Use the numbering wizard: it has you plug them in one at a time.

Numbering wizard

Give every dongle its own serial, one at a time.
About a minute per dongle. Stop the rtlnc core first (it keeps the dongles busy). Have a marker or labels ready.

Connected dongles

#Serial (in dongle)NameRoleGain dBBias-TNotes
Serial is written into the dongle's EEPROM (up to 14 characters; a backup is saved first and the write is verified). A new serial appears after you unplug and replug. Name / role / gain / bias-T / notes are saved on this PC and used by rtlnc run (roles main, aux1, aux2… pick which dongle is which) and by the control panel.
Tip: unplug or plug a dongle and this page tells you which one it was.
